data writing:

df.write.format('csv').save('path')

| Format                 | Example                                           |
| ---------------------- | ------------------------------------------------- |
| **CSV**                | `df.write.csv("/path/to/folder")`                 |
| **Parquet**            | `df.write.parquet("/path/to/folder")`             |
| **JSON**               | `df.write.json("/path/to/folder")`                |
| **ORC**                | `df.write.orc("/path/to/folder")`                 |
| **JDBC** (DBs)         | `df.write.jdbc(url, table, properties=props)`     |
| **Delta (Databricks)** | `df.write.format("delta").save("/path/to/delta")` |

You can specify how Spark handles existing data:

"overwrite" – replaces data

"append" – adds new data

"ignore" – skips if data exists

"error" (default) – throws error if exists

append:
df.write.format('csv').mode('appennd').option('path',location).save()

df.write.format('csv').mode('error').option('path',location).save()
